# 🌊 Avatar Characters API - #7DaysOfCode Python

![Python](https://img.shields.io/badge/Python-3.x-blue?style=for-the-badge&logo=python)
![Status](https://img.shields.io/badge/Status-Em_Desenvolvimento-orange?style=for-the-badge)
![Challenge](https://img.shields.io/badge/Desafio-%237DaysOfCode-brightgreen?style=for-the-badge)

Projeto desenvolvido durante o desafio **#7DaysOfCode** da [Alura](https://github.com/alura), com mentoria de [Guilherme Lima](http://github.com/guilhermeonrails). 

O objetivo principal deste projeto é aplicar conceitos práticos de backend, consumo de APIs RESTful, boas práticas de estruturação de código Python e controle de versão com Git/GitHub.

---

## 🎯 Objetivos de Aprendizado

- Consumir e manipular requisições HTTP (`GET`) utilizando a biblioteca `requests`.
- Tratar e estruturar dados recebidos em formato JSON.
- Aplicar boas práticas de arquitetura modular em Python (separação de responsabilidades em `src/`).
- Gerenciar ambientes virtuais com `venv` e isolar dependências.
- Desenvolver um projeto completo de portfólio documentado passo a passo.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Python 3
- **Biblioteca HTTP:** `requests`
- **Ferramentas de Teste de API:** Postman
- **Ambiente de Desenvolvimento:** Visual Studio Code no Linux Mint / WSL2
- **Controle de Versão:** Git e GitHub

---

## 📂 Estrutura do Projeto

```text
avatar-api-7days/
│
├── venv/                 # Ambiente virtual isolado
├── src/                  # Código-fonte da aplicação
│   ├── __init__.py       # Inicializador do pacote Python
│   ├── main.py           # Ponto de entrada da aplicação
│   └── avatar_client.py  # Módulo responsável pelas chamadas HTTP à API
│
├── .gitignore            # Arquivos e pastas ignorados pelo Git
├── requirements.txt      # Dependências do projeto
└── README.md             # Documentação do repositório
```
